# 鹿城项目规则

用户于 2026-10-09 指定本聊天后续负责《鹿城》2D 搞笑动画。

- 项目目录：`../../../鹿城/`。
- 权威归纳入口：[项目资料归纳](../../../鹿城/项目资料归纳.md)。历史文本：[来源索引](../../../鹿城/资料来源/索引.md)。
- 2D 夸张搞笑动漫、16:9 横屏、清晰二维线稿、平涂色块、简洁阴影，覆盖 3D 默认值。
- 主线正常比例与 Q 版白底小剧场分别管理；纯白、远景、人物不超过 33% 等属于小剧场要求，不强加到主线。
- 小剧场强化连续动作演绎，近期去掉颜艺插帧，避免 PPT 感。
- 最新用户修正优先于历史助手稿，不把拟稿、旧版与最终确认混合。
- 角色持物、站位、口罩、眼镜、人数按当前单元锁定；孙鸽与墨镜保镖明确区分。
- 不继承《琥珀之城》或《赤卷》的设定；不覆盖其文件。
- 平台、声线与最终参考图尚未核定，影响任务时再补齐。
